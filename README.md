# Спектрограф

iOS-приложение для iPhone SE (2016): анализ звука в реальном времени и вывод
спектрограммы («водопад»). Источник сигнала — встроенный микрофон.

## Что делает

- Захват звука через `AVAudioEngine`, моно-микс стерео.
- Быстрое преобразование Фурье (`vDSP` / `Accelerate`), окно Ханна, уровень в дБFS.
- Спектрограмма: время по горизонтали (свежие столбцы справа), частота по вертикали.
- Отображение рисуется в битмап-слой (`CGContext` + `CALayer.contents`), обновление через `CADisplayLink`.
- Индикация уровня сигнала (дБFS) и пиковой частоты (троттлинг ~7 Гц).
- Экспорт текущей спектрограммы в PNG с подписями осей (системный лист «Поделиться»).
- Разделение звука на отдельные составляющие и их прослушивание (см. ниже).

## Разделение звука на составляющие

Есть два способа — автоматический и ручной.

### Автоматически

1. Нажмите «Старт» и запишите звук, затем «Стоп».
2. Нажмите «Авто» — приложение само разложит запись на составляющие и откроет
   список «Составляющие звука»:
   - отдельные устойчивые **тона** (по их гармоникам), например «Тон 1 · 440 Гц»;
   - **«Прочие тона»** — тональные источники послабее;
   - **«Ударные»** (стук, щелчки) — транзиенты;
   - **«Шум / остаток»** — гармоническое, не объяснённое отдельными тонами.
3. Каждую составляющую можно прослушать (▶) и сохранить как WAV (↑).

Метод (чистый DSP, без нейросетей, работает офлайн):
короткое преобразование Фурье → гармонико-перкуссионное разделение (HPSS)
медианными фильтрами → поиск основных тонов по гармонической значимости →
отслеживание тонов во времени → маски компонентов → обратное преобразование.

Ограничение: звуки, совпадающие по частоте и времени, разделить нельзя;
лучше всего разделяются тональные и ударные звуки.

### Вручную

1. Нажмите «Старт» и запишите звук, затем «Стоп». Запись сохраняется в памяти.
2. Проведите пальцем по спектрограмме — выделится прямоугольная область
   «частота × время». Так можно выделить отдельную составляющую (тон, шум, щелчок).
3. Кнопки:
   - «Выдел.» — проигрывает только выделенные области (изолированные звуки);
   - «Остал.» — проигрывает всё, кроме выделенного;
   - «⋯» — прослушать оригинал, список выделений (каждую составляющую отдельно)
     или очистить всё.
4. В меню экспорта (↑) доступны: PNG спектрограммы и WAV-файлы
   «выделенное», «остальное», «оригинал».

Как это работает: короткое преобразование Фурье с перекрытием (`SpectralProcessor`),
на спектр выделения накладывается маска, затем звук пересобирается обратным
преобразованием с взвешенным перекрытием (Hann, шаг = БПФ/2). Нормировка обратного
БПФ калибруется автоматически при запуске, поэтому уровень восстанавливается точно.

Примечание: после «Стоп» запись обрезается до видимого окна спектрограммы — так
выделение на экране однозначно соответствует участку звука.


## Настройки

- Размер БПФ: 512 / 1024 / 2048 / 4096.
- Максимальная частота: 2 / 4 / 8 / 16 кГц.
- Логарифмическая шкала частот.
- Динамический диапазон: 40 / 60 / 80 / 100 дБ (верхняя граница −10 дБFS).
- Цветовая схема: Turbo / Viridis / Inferno / оттенки серого.

## Сборка

Проект Xcode генерируется из `project.yml` через XcodeGen. Локальный Swift-тулчейн
не нужен: сборка идёт на GitHub Actions (`.github/workflows/build-ipa.yml`),
на выходе — неподписанный `.ipa` (artifact `Spectrograph-ipa`).

Порядок:

1. GitHub Actions собирает `Spectrograph.ipa` без подписи.
2. Скачанный `.ipa` подписывается вашим Apple ID в Sideloadly на Windows.
3. Установка на iPhone.

## Структура

- `Spectrograph/` — исходники приложения.
  - `FFTProcessor.swift` — БПФ на vDSP.
  - `SpectrogramSettings.swift` — настройки, палитры, расчёт осей.
  - `Waterfall.swift` — пиксельный буфер и слой «водопада».
  - `AudioAnalyzer.swift` — захват звука и обработка.
  - `AudioStore.swift` — накопление записанного звука для анализа.
  - `SpectralProcessor.swift` — выделение/маскирование спектра и пересборка звука.
  - `AutoSeparator.swift` — автоматическое разложение на тона, ударные и шум.
  - `AudioOutput.swift` — запись WAV и воспроизведение.
  - `SpectrogramView.swift` — мост SwiftUI ↔ UIKit, оси, слой выделения, экспорт PNG.
  - `ContentView.swift` — интерфейс и экран настроек.
  - `ShareSheet.swift` — системный лист «Поделиться».
- `project.yml`, `.github/workflows/build-ipa.yml` — конфигурация и CI.

## Требования

- iPhone SE (2016), iOS 15.0 или новее.
- Разрешение на доступ к микрофону.
