# Спектрограф

iOS-приложение для iPhone SE (2016): анализ звука в реальном времени и вывод
спектрограммы («водопад»). Источник сигнала — встроенный микрофон.

## Что делает

- Захват звука через `AVAudioEngine`, моно-микс стерео.
- Быстрое преобразование Фурье (`vDSP` / `Accelerate`), окно Ханна, уровень в дБFS.
- Спектрограмма: время по горизонтали (свежие столбцы справа), частота по вертикали.
- Отображение рисуется в битмап-слой (`CGContext` + `CALayer.contents`), обновление через `CADisplayLink`.
- Индикация уровня сигнала (дБFS) и пиковой частоты (троттлинг ~7 Гц).
- Экспорт текущей спектрограммы в PNG с подписями осей (системный лист «Поделиться»).

## Настройки

- Размер БПФ: 512 / 1024 / 2048 / 4096.
- Максимальная частота: 2 / 4 / 8 / 16 кГц.
- Логарифмическая шкала частот.
- Динамический диапазон: 40 / 60 / 80 / 100 дБ (верхняя граница −10 дБFS).
- Цветовая схема: Turbo / Viridis / Inferno / оттенки серого.

## Сборка

Проект Xcode генерируется из `project.yml` через XcodeGen. Локальный Swift-тулчейн
не нужен: сборка идёт на GitHub Actions (`.github/workflows/build-ipa.yml`),
на выходе — неподписанный `.ipa` (artifact `Spectrograph-ipa`).

Порядок:

1. GitHub Actions собирает `Spectrograph.ipa` без подписи.
2. Скачанный `.ipa` подписывается вашим Apple ID в Sideloadly на Windows.
3. Установка на iPhone.

## Структура

- `Spectrograph/` — исходники приложения.
  - `FFTProcessor.swift` — БПФ на vDSP.
  - `SpectrogramSettings.swift` — настройки, палитры, расчёт осей.
  - `Waterfall.swift` — пиксельный буфер и слой «водопада».
  - `AudioAnalyzer.swift` — захват звука и обработка.
  - `SpectrogramView.swift` — мост SwiftUI ↔ UIKit, оси, экспорт PNG.
  - `ContentView.swift` — интерфейс и экран настроек.
  - `ShareSheet.swift` — системный лист «Поделиться».
- `project.yml`, `.github/workflows/build-ipa.yml` — конфигурация и CI.

## Требования

- iPhone SE (2016), iOS 15.0 или новее.
- Разрешение на доступ к микрофону.
